Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos na área de tecnologia.

## 📋 Sobre

Site de portfólio criado do zero para centralizar minhas informações profissionais e acadêmicas, servindo como cartão de visitas digital para recrutadores e outros profissionais da área de TI.

- Habilidades técnicas

- Formação acadêmica

- CSS

## ⚡ Projeto em destaque: PayFast

O portfólio agora apresenta o **PayFast — Motor de Transações e Liquidação de Pix**, um projeto acadêmico desenvolvido em PostgreSQL com modelagem relacional, normalização até a 3FN, integridade referencial, DDL, DML e modelo DBML.
